# 𓂀 古代エジプト壁画録 | Yoshika Fukuyama Portfolio

悠久のナイルの風、エジプシャンブルーと黄金、パピルスと砂岩の石碑をモチーフにした**古代エジプト壁画風ポートフォリオサイト**です。  
現代のデジタル書記官（Scribe）として、Webフロントエンド開発やUIデザインの成果、そして愛する「放浪・旅路」の記憶を石板レリーフに刻み込んでいます。

---

## ✨ 意匠と特長（Features）

- **古代エジプト壁画＆石碑レリーフの世界観**:
  - パピルス紙、砂岩テクスチャ、黄金（Gold）、エジプシャンブルー（Lapis Lazuli）、ターコイズ（碧緑）の崇高なカラーパレット。
  - カルトゥーシュ（ファラオの王名枠）、ホルスの目（𓂀）、アンク（☥）、聖なるスカラベやヒエログリフ（象形文字）による装飾。
  - 壁画風の肖像画フレームとコーナー金具オーナメント。
- **旅路の記録（Voyage & Travel Journal）**:
  - 大河や海の碧さ、悠久の石造建築からインスピレーションを得る旅のストーリーと旅ログアプリ「TabiLog」の奉納石板。
- **昼夜の儀式（テーマ切り替え）**:
  - 太陽神ラーの光が降り注ぐ「砂岩パピルス昼モード」と、ピラミッド玄室の松明が揺らめく「ナイト神殿モード」をワンクリックで切り替え可能。
- **完全レスポンシブ＆アニメーション**:
  - スマートフォン・タブレット・PCに対応。石板が浮き彫りになるようなスクロール演出とスキルメーター。
- **GitHub Pages 完全対応**:
  - 静的ファイル（HTML / CSS / JS）のみで動作し、`.nojekyll`設定済み。

## 🚀 GitHub Pages への公開手順

すでにローカルリポジトリで初期コミット済みですので、以下の手順で即座に全世界へ公開できます。

### 1. GitHubでリポジトリを作成
1. [GitHub](https://github.com) にログイン。
2. 画面右上の **「+」** → **「New repository」** をクリック。
3. リポジトリ名を入力（例: `portfolio`）。
4. **Public** を選択し、初期化オプションは未チェックのまま **「Create repository」** をクリック。

### 2. ローカルからプッシュ
ターミナル（PowerShell等）で以下のコマンドを実行します：

```powershell
# GitHubリポジトリURLを紐付け
git remote add origin https://github.com/<あなたのユーザー名>/portfolio.git

# mainブランチへプッシュ
git push -u origin main
```

### 3. GitHub Pagesを有効化
1. リポジトリの **Settings** > **Pages** を開きます。
2. **Branch** で `main`（フォルダは `/root`）を選択し、**Save** をクリック。
3. 数分後、ページ上部に表示されるURL（`https://<ユーザー名>.github.io/portfolio/`）からアクセスできます。
